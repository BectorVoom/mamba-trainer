# Database-first molecular-completion experiments

Research note, 2026-10-03. This is an experimental plan, not a measured result.
It extends the [completion design](MOLECULAR_COMPLETION_DESIGN.md) and the
[small synthetic pilot](MOLECULAR_COMPLETION_PILOT_RESULTS.md).

## Main decision

Measure how far existing structures and cheap exact constraints can take the
task before training a Mamba-3 decoder or running new quantum calculations.
The first benchmark should retrieve and filter known graphs. Generation is
evaluated separately on cases where a reference pool misses the target.

This distinction matters for the requested inputs. A precursor neutral mass,
target neutral mass and open substructures can describe completion of a parent
or of a fragment, depending on `mass_role`. Public MS/MS records commonly pair
a precursor structure with a spectrum, but peak masses do not identify the
connectivity of each fragment. Synthetic parent subgraphs generated by cutting
known molecules are useful for a controlled completion test; they must not be
reported as experimentally confirmed fragment structures.

The [MassSpecGym project](https://github.com/pluskal-lab/MassSpecGym) supplies
official retrieval and formula tasks, predefined splits, and a simple
fingerprint-based baseline. Its dataset card lists a roughly 52 GB repository,
with substantially smaller main-table and candidate resources. Pin a release
or dataset revision and record hashes rather than downloading every pretraining
file. License and provenance checks apply to constituent data even when the
benchmark repository itself displays an MIT license.

## Experiment A: database coverage and ambiguity

Use one pinned ChEBI 3-star structure export, then repeat on the predefined
MassSpecGym candidate pools. Standardize atom types, charge, isotopes, salt
fragments, tautomer and stereochemical identity according to the completion
domain. Retain source IDs and the original records. Compute neutral monoisotopic
mass from the validated graph using the repository's integer arithmetic, rather
than treating a source's rounded display mass as ground truth.

For each held-out target structure, make controlled open-subgraph queries using
the parent-relative hydrogen convention. Stratify by heavy-atom count, number
of supplied subgraphs, overlap, residual valence, formula uniqueness and
structure family. Compare four candidate sets on identical queries:

1. Mass window only, with accepted, rejected and boundary-ambiguous decisions
   reported separately.
2. Exact formula plus charge/element domain.
3. Required typed subgraph containment and overlap consistency.
4. The same constraints with any actual precursor evidence that exists.

Record candidate count and target recall after every step. A zero count may
mean that the reference database lacks the target; it is not a proof that the
chemical constraints are inconsistent. For known-overlap and unknown-overlap
conditions, preserve provenance so mappings from the target are never leaked
to the unknown-overlap query.

Keep the earlier [bounded grammar experiment](MOLECULAR_COMPLETION_EXPERIMENT.md)
as a small-domain cross-check. Database counts measure *known-structure
coverage*; bounded enumeration measures *in-domain completions* when it
terminates. Compare them only on the common domain.

## Experiment B: retrieval before generation

Start from MassSpecGym's supplied candidate lists. Build a local index keyed
by formula, heavy-atom count and charge. Store connectivity identity and a
substructure-screening fingerprint once. For each query, filter formula/mass,
screen with the fingerprint and confirm surviving hits with an exact typed graph
match. The fingerprint must be used only as a sound rejection screen for the
chosen pattern semantics; its hits still need exact matching. Cache graph
standardization, identity and fingerprints across queries.

Compare these ranking baselines at the same candidate pool: uniform order,
database provenance/frequency, simple spectral similarity where a spectrum is
available, and MassSpecGym's supplied fingerprint baseline. Only add a small
learned ranker or Mamba-3 model if a measured gap remains. Report top-1/top-k
accuracy only when the target is present in the candidate pool, alongside
candidate-pool recall on *all* queries. Otherwise a ranker can look better by
silently dropping hard targets.

For PubChem expansion, query only unresolved formulas, batch property requests,
cache results by formula and database release, respect throttling and backoff,
and prefer bulk data once the query set becomes large. Compare its marginal
target recall and cost against the smaller sources. Do not use a live remote
search as the sole ground truth for a reproducible benchmark.

## Experiment C: measured spectra and physical evidence

Use the pinned MassSpecGym split first, then MassBank and license-compatible
GNPS records as an external check. Join structures by a stated connectivity or
stereo-aware identity; deduplicate molecules across sources *before* training
and evaluation splits. Keep each measured spectrum's ion/adduct, polarity,
collision energy and instrument metadata. Reject records whose precursor
neutral-mass conversion is unsupported or ambiguous. Separate target-parent
reconstruction from synthetic fragment-completion evaluation.

For physical evidence, match only small candidates into QM9 and use its
existing geometry/frequency results as a restricted positive-control set.
The main retrieval experiment can use basic graph validity and established
database presence without running conformer optimization at all. If physical
checks later change ranking materially, run force-field conformers only for
a small, predeclared shortlist; reserve xTB or DFT for unresolved cases. The
score must not equate database occurrence, a force-field minimum or an MS/MS
peak with kinetic stability.

## Resource and quality gates

Begin with a capped, representative sample, then expand only if confidence
intervals or subgroup counts are inadequate. Record wall time, CPU time, peak
RAM, disk bytes, downloaded bytes and API calls per 1,000 queries. Cache and
pin all data transformations. A simple SQLite/Parquet index and CPU graph
matching are sufficient for the first pass; GPU training is an experimental
cost to justify with improved recall or ranking.

Before scaling, publish these denominators:

- Fraction of records with parseable structure, compatible charge/adduct and
  known mass precision.
- Fraction inside the versioned chemistry and graph-size domain.
- Target-in-candidate-pool recall before and after each filter.
- Fraction with exact, ambiguous, missing or truncated search outcomes.
- Molecule and scaffold overlap across train/validation/test and data sources.
- Physical-label coverage and the method/environment attached to each label.

Stop after the database stage if formula and subgraph filtering already leaves
few candidates with high reference recall. If ambiguity remains high, test a
cheap ranker and calibrated abstention. Invest in Mamba-3 generation only for
the measured out-of-pool or hard-ranking slice, and compare against retrieval
at equal candidate and compute budgets.

No external dataset was downloaded or benchmark run for this note. The source
claims above were checked against the linked providers on 2026-10-03; source
licenses, release formats and API limits should be verified again when data
ingestion is implemented.
