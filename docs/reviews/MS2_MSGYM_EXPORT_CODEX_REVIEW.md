# Codex review: MassSpecGym export tools

Reviewer: codex exec (read-only), 2026-10-03. Scope: tools/ms2/export_msgym.py, formula_table_msgym.py, formula_table.py refactor. Findings 1 and 2 were fixed (fold-conflict exclusion, peak validation); finding 3 was declined: the whole-file hash identifies the pinned file (data/pinned/PIN.json records the same hash) and no test-row content enters an export.

1. **Major — [export_msgym.py:199](tools/ms2/export_msgym.py:199): spectra are not restricted to their molecule’s assigned fold.** Pass 1 assigns each SMILES the first encountered fold, but pass 2 accepts both train and val rows for that SMILES. With identical SMILES in one train row followed by one val row, I reproduced both spectra appearing in the train export. **Fix:** reject conflicting fold assignments explicitly, and enforce each candidate row’s fold against its molecule’s subset. The pinned non-test data currently has no such overlap.

2. **Major — [export_msgym.py:204](tools/ms2/export_msgym.py:204): numeric parsing admits values that crash export or violate the Rust schema.** `parse_floats` accepts `nan`, infinity and negative m/z; eligibility checks only list lengths and precursor validity. I reproduced `mzs=nan` crashing during integer conversion, and `mzs=-1` exporting `mz_udalton=[-1000000]`, which cannot deserialize into Rust’s `Vec<u32>`. Nonfinite intensity can also produce invalid JSON. **Fix:** validate peak values before sampling, including finiteness, unsigned integer representability and valid intensity bounds; count rejected rows in `skipped_spectra`.

3. **Minor — [export_msgym.py:129](tools/ms2/export_msgym.py:129): test-fold contents influence output through the whole-file hash.** `sha256_of` reads every byte, including test rows, and embeds the digest in every export. Changing only a test-row value therefore changes output despite the stated prohibition on reading test rows. **Fix:** hash the header and permitted non-test rows for export provenance. This is provenance dependence, not evidence that test spectra enter training.

No correctness regression found in the `formula_table.py` refactor or the formula-table twin’s normal nonempty-input behavior. Precision inference matches CASMI and tolerates float representation artifacts; energy/instrument IDs, top-512 ties and peak IDs match the loader. Both scaffold paths consistently use kekulized molecules. No files were modified.
